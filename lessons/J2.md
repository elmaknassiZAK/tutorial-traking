# J2 · Lists, liens, images, tables

> **L hadaf dyal lyoum :** t7kem f les listes, les liens, les images w les tableaux.

## 0. Révision (10 d, bla notes)

Jaweb f rassek, men be3d t2akked :
1. Chnou l far9 bin `<head>` w `<body>` ?
2. Chnou dawr dyal `alt` f `<img>` ?
3. Kteb men rassek structure kamla dyal page HTML.

## 1. Les listes

```html
<!-- Liste bla tartib -->
<ul>
  <li>Khobz</li>
  <li>Atay</li>
</ul>

<!-- Liste mr9ma -->
<ol>
  <li>Ghsel yddik</li>
  <li>Kol</li>
</ol>

<!-- Liste dakhel liste -->
<ul>
  <li>Frontend
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Backend</li>
</ul>
```

> 💡 `<ol type="A">` kaymr9em b A, B, C. `<ol start="5">` kaybda men 5.

## 2. Les liens

```html
<!-- Lien externe, kay7el f onglet jdid -->
<a href="https://developer.mozilla.org" target="_blank">MDN</a>

<!-- Lien l page khra f nefs l site -->
<a href="about.html">À propos</a>

<!-- Lien l section f nefs l page -->
<a href="#contact">Sir l contact</a>
...
<h2 id="contact">Contact</h2>

<!-- Email w telephone -->
<a href="mailto:test@mail.com">Sifet email</a>
<a href="tel:+212600000000">3ayet</a>
```

## 3. Chemins relatifs (mohim bzaf)

Ila 3endek had structure :

```
mon-site/
├── index.html
├── about.html
├── images/
│   └── logo.png
└── pages/
    └── contact.html
```

| Men fin | L fin | Chemin |
|---|---|---|
| `index.html` | `logo.png` | `images/logo.png` |
| `index.html` | `contact.html` | `pages/contact.html` |
| `contact.html` | `index.html` | `../index.html` |
| `contact.html` | `logo.png` | `../images/logo.png` |

> 💡 `../` = tla3 dossier wa7ed l fo9.

## 4. Images

```html
<img src="images/logo.png" alt="Logo dyal site" width="200">

<!-- Image m3a légende -->
<figure>
  <img src="images/maroc.jpg" alt="Marrakech">
  <figcaption>Jemaa el-Fna f l3chiya</figcaption>
</figure>
```

## 5. Les tableaux

```html
<table>
  <thead>
    <tr>
      <th>Nhar</th>
      <th>Mawdou3</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Lthnin</td>
      <td>HTML</td>
    </tr>
    <tr>
      <td>Tlat</td>
      <td>CSS</td>
    </tr>
  </tbody>
</table>
```

- `tr` = table row (ster)
- `th` = header (khana dyal titre)
- `td` = data (khana 3adiya)

> 💡 Bach tzid border bla CSS mo9tan : `<table border="1">`. Ghedda nhar CSS ghadi ndiroha b tari9a s7i7a.
