## 1. Structure dyal formulaire

```html
<form action="/inscription" method="POST">
  <label for="nom">Smiya</label>
  <input type="text" id="nom" name="nom">

  <button type="submit">Sifet</button>
</form>
```

- `action` : fin ghadi tmchi data (l serveur). Daba ma3endnach serveur, 3adi.
- `method` : `GET` (data kayban f URL, l recherche) wla `POST` (data mkhbiya, l login w inscription).
- `label for="nom"` mrbout b `input id="nom"` : ila cliquiti 3la label, input kaytselecta. **Dima** dir label.
- `name` : smiya dyal data li ghadi tsifet l serveur.

## 3. Checkbox w radio

```html
<!-- Checkbox : t9der tkhtar bzaf -->
<p>Chnou kat7eb ?</p>
<label><input type="checkbox" name="hobby" value="foot"> Football</label>
<label><input type="checkbox" name="hobby" value="code"> Code</label>

<!-- Radio : wa7ed ghir. Khass nefs name -->
<p>Niveau dyalek :</p>
<label><input type="radio" name="niveau" value="debutant"> Débutant</label>
<label><input type="radio" name="niveau" value="moyen"> Moyen</label>
```

> ⚠️ Radio bla nefs `name` = t9der tkhtar kolhom, w hada bug.

## 4. Select w textarea

```html
<label for="ville">Mdina</label>
<select id="ville" name="ville">
  <option value="">-- Khtar --</option>
  <option value="rabat">Rabat</option>
  <option value="casa">Casablanca</option>
</select>

<label for="msg">Message</label>
<textarea id="msg" name="msg" rows="4"></textarea>
```

## 5. Validation bla JavaScript

```html
<input type="email" required>
<input type="text" minlength="3" maxlength="20" required>
<input type="password" pattern=".{8,}" title="8 caractères au moins">
```

`required` kaymn3 l'envoi ila l khana khawya. Jerreb : cliqui "Sifet" bla ma t3emmer.
