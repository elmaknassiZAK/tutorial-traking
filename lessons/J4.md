## 1. L mochkil : "div soup"

Hada code khdam, walakin ma fih ta ma3na :

```html
<div class="top">
  <div class="menu">...</div>
</div>
<div class="content">
  <div class="post">...</div>
</div>
<div class="bottom">...</div>
```

Navigateur, Google, w lecteur d'écran ma kay3erfo walo : fin l menu ? fin l contenu l asasi ?

## 2. L 7el : tags sémantiques

```html
<header>
  <nav>
    <a href="/">Accueil</a>
    <a href="/blog">Blog</a>
  </nav>
</header>

<main>
  <article>
    <h1>Titre dyal article</h1>
    <p>...</p>
  </article>

  <aside>
    <h2>Articles khrin</h2>
  </aside>
</main>

<footer>
  <p>© 2026 Site dyali</p>
</footer>
```

| Tag | Mli tkhdem bih |
|---|---|
| `header` | L fo9 dyal page (wla dyal article) : logo, titre, menu |
| `nav` | Groupe dyal liens dyal navigation |
| `main` | L contenu l asasi. **Merra wa7da** f page |
| `section` | Jiha dyal page 3endha titre dyalha |
| `article` | Contenu mosta9el (post, produit, commentaire) |
| `aside` | Contenu jenbi (sidebar, liens mrbotin) |
| `footer` | L te7t : copyright, contact, liens |

> 💡 Qa3ida : ila kan l contenu y9der yt9ra bo7do (bhal tweet), `article`. Ila kan ghir jiha mn page, `section`. Ila ma3endo ta ma3na, `div`.

## 3. Titres b tartib

```html
<h1>Smiyt l page</h1>        <!-- wa7ed ghir -->
  <h2>Section 1</h2>
    <h3>Sous-section</h3>
  <h2>Section 2</h2>
```

> ⚠️ Ma tnz9ch men `h2` l `h4`. W ma tkhtarch `h3` 7it sghir : taille katbeddel b CSS.

## 4. Accessibilité asas

1. **`alt` f kol image.** Image dyal décoration ? `alt=""` (khawi, machi ma kaynch).
2. **`label` f kol input.**
3. **`lang` f `<html>`** : `<html lang="fr">` wla `lang="ar"`.
4. **`button` l actions, `a` l navigation.** Ma tdirch `<div onclick>`.
5. **Texte dyal liens wad7** : "Chouf les projets" machi "Cliqui hna".
