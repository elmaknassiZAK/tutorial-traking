## 1. Wjjed l'environnement

1. Install **[VS Code](https://code.visualstudio.com/)**.
2. F VS Code, sir l Extensions (`Ctrl + Shift + X`) w install **Live Server**.
3. Dir dossier smiyto `frontend-course` w 7llo f VS Code (`File > Open Folder`).

## 2. Chnou howa HTML ?

Kol page web mbniya b 3 7wayej :

| Logha | Dawr dyalha | Mithal |
|---|---|---|
| **HTML** | Squelette : chnou kayn f page | titre, paragraphe, image |
| **CSS** | Design : kifach kayban | couleur, taille, position |
| **JavaScript** | 7araka : chnou kaydir | click, animation, data |

HTML mbni b **tags**. Kol tag kayftah w kaysedd :

```html
<p>Hada paragraphe</p>
```

- `<p>` : tag d'ouverture
- `</p>` : tag de fermeture (fiha `/`)
- Binathom : l contenu

## 3. Structure dyal ay page HTML

Dir fichier `index.html` w ktb fih **bidek** (ma tcopich) :

```html
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Page dyali</title>
</head>
<body>
  <h1>Salam, ana smiti ...</h1>
  <p>Ana kant3lem frontend.</p>
</body>
</html>
```

- `<!DOCTYPE html>` : kaygoul l navigateur "hada HTML5".
- `<head>` : ma3loumat 3la l page (ma katbanch), bhal `title` li kayban f l'onglet.
- `<body>` : kolchi li kayban l l'utilisateur.

**Testi :** cliqui droit 3la fichier > **Open with Live Server**.

## 4. Tags l asasiyin

```html
<h1>Titre kbir</h1>
<h2>Sous-titre</h2>
<!-- h3, h4, h5, h6 kaysgharo -->

<p>Paragraphe</p>

<ul>
  <li>Element 1</li>
  <li>Element 2</li>
</ul>

<a href="https://google.com">Lien l Google</a>

<img src="https://picsum.photos/200" alt="Description dyal image">

<strong>Ghlid (mohim)</strong> w <em>mayl</em>
```

> 💡 `<!-- ... -->` howa commentaire f HTML, ma kaybanch f page.

> ⚠️ `<img>` ma 3endhach tag de fermeture. `alt` mohim bzaf : kayt9ra mn les lecteurs d'écran w kayban ila l'image ma t7mlatch.
