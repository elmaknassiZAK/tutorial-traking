# J6 · Git + GitHub asas

> **L hadaf dyal lyoum :** tfhem Git w tpushi les projets dyalek l had repo b rassek. Men lyoum, kol projet kaytla3 l GitHub.

## 0. Révision (10 d)

Kteb men rassek formulaire fih email, password w bouton, b labels.

## 1. Chnou howa Git ?

- **Git** : logiciel kaysjjel l'historique dyal code dyalek. Kol "photo" smitha **commit**. Ila khserti chi haja, katrj3 l commit 9dim.
- **GitHub** : site fin kat7et l code dyalek online (backup, portfolio, khedma m3a nas).

## 2. Installation (Windows)

1. Telechargi **[Git for Windows](https://git-scm.com/download/win)** w install (khlli les options par défaut).
2. 7el **Git Bash** w 3erref rassek (merra wa7da) :

```bash
git config --global user.name "elmaknassiZAK"
git config --global user.email "email-dyal-github@mail.com"
git --version
```

## 3. Clone had repo

```bash
cd ~/Desktop
git clone https://github.com/elmaknassiZAK/tutorial-traking.git
cd tutorial-traking
code .
```

Daba 3endek nefs l platforme f l'ordinateur, w VS Code m7loul fiha.

## 4. Cycle dyal kol nhar

```
 Tbeddel fichiers  →  git add  →  git commit  →  git push
   (working dir)     (staging)     (historique)    (GitHub)
```

```bash
git status                     # chnou tbeddel ?
git add projects/j1-profil/    # 7et l changements f staging
git commit -m "J1 : page dyal profil"
git push                       # tla3 l GitHub
```

> 💡 `git add .` kayzid kolchi. Mzyan, walakin dima dir `git status` 9bel bach tchouf chnou ghadi yt7et.

## 5. Commandes khrin naf3in

```bash
git log --oneline     # historique dyal commits
git diff              # chnou tbeddel bdbt (9bel add)
git pull              # jib changements men GitHub (ila Claude update chi haja)
git restore fichier   # rja3 fichier kif kan f akhir commit
```

> ⚠️ **Dima `git pull` 9bel ma tbda tkhdem**, 7it ana kanpushi updates l progress w les cours.
